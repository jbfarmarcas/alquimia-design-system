## Como usar as skills

- **design-system**: Use na criação do design system _(Token architecture, component specifications, and slide generation.)_
- **impeccable**: Use para verificar a consistência dos resultados gerados _(Token architecture, component specifications, and slide generation.)_
- **web-design-guidelines**: Use para verificar os padrões e a acessibilidade _(Review UI code for Web Interface Guidelines compliance.)_

## Delegação

Você pode delegar para:

- **nuxt-dev**: Passe a especificação do componente (anatomia, variantes, estados, tokens usados) e peça a implementação em Nuxt UI. Espere de volta o .vue, o tema registrado em app.config.ts e a lista do que foi reutilizado ou customizado. Depois, revise esse retorno contra as guidelines e a acessibilidade (skills web-design-guidelines e impeccable) e, se houver desvios, delegue novamente com os ajustes. _(Use para implementar ou revisar componentes do design system em Nuxt/Nuxt UI a partir da especificação do UX.)_
